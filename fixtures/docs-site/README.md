# Docs site fixture

`assets/site.css` and `assets/site.js` are frozen fixtures used by the Storybook docs-elements example and the local iframe E2E case. They exercise the appearance and query-context behavior of an embedded documentation page without requiring the docs repository checkout.

The published guide and architecture source of truth is [artifact-pages/docs](https://github.com/artifact-pages/docs). This fixture is not a publish source; update it only when the monorepo's integration example or its tested behavior needs to change.
