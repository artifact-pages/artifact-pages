# Registry consumer example

This example targets `artifact-pages/artifact-pages/aws` and pins the first planned module version, `0.1.0`. The package repository is generated from the monorepo when `terraform-aws/v0.1.0` is released; Terraform Registry publication is a separate owner-controlled step. `terraform init` can retrieve this source after Registry lists that exact version. `bucket_name` is an optional override; when omitted, the module derives its deterministic default from the AWS provider target account and `aws_region`. Planning performs a read-only account identity lookup and requires that account to match `github_oidc_provider_arn`. Provide real values through an untracked variable file, configure AWS credentials through the standard credential chain, and review the full plan before apply.
