# Registry consumer example

This example pins an exact module version (the generated package sets it to that package's release) at `artifact-pages/artifact-pages/aws`. The package repository has been generated and synced from the matching monorepo tag `terraform-aws/vX.Y.Z`; each release is published on the public Terraform Registry. A caller can also use the Git source `git::https://github.com/artifact-pages/terraform-aws-artifact-pages.git?ref=vX.Y.Z` with the release tag in place of `vX.Y.Z`, without `version`. `bucket_name` is an optional override; when omitted, the module derives its deterministic default from the AWS provider target account and `aws_region`. Planning performs a read-only account identity lookup and requires that account to match `github_oidc_provider_arn`. Provide real values through an untracked variable file, configure AWS credentials through the standard credential chain, and review the full plan before apply.
