repo・処理・objectを一度ずつ置いた関係図

同じ管理repoや保存objectは一つのノードだけにし、どの処理が読み書きするかを矢印でつないでいます。

Gitが正本ストレージはGitから再生成できる配信projection。CDNはその読み取りcacheです。

作成・更新 読み込み 削除・無効化要求 同一siteのlock

配信時は sites.json → meta.json → index.json → artifact。localは /_indexes/ のdirectory listingから発見。

CDN TTLはindex最大60秒、artifact最大300秒。解除後のedge反映は結果整合。
