オブジェクト台帳

先頭の / は配信URL表記です。S3などのobject keyでは先頭のslashを除きます。

論理object作成・更新する人読む人削除・保持
/index.html管理側のアプリ配備ブラウザ新しいshellで置換。配備後にこのpathをCDN無効化。
/assets/<content-hash>/*管理側のアプリ配備ブラウザ変更ごとに新しいURLを作成。古いhashed assetの掃除方針は未確定。
/_indexes/sites.json管理側のregistry反映ブラウザ、各siteのpublish処理登録変更時に置換。site単位publish / 削除では消さない。
/_indexes/<site>/meta.jsonsite publishブラウザsite unregister時に削除。初回登録時の空ファイル生成は未決。
/_indexes/<site>/index.jsonsite publishブラウザsite unregister時に削除。初回登録時の空ファイル生成は未決。
/_artifacts/<site>/**site publishブラウザ同期時にstale objectsを削除。unregister時はsite配下を全削除。
/_control/locks/<site>.jsonsite publish / 管理側のunregister同じ操作主体CASでfree/heldを更新。公開せず、unregister後もfreeで保持。

管理側の権限

アプリ面とregistryを書き換える。unregisterではsite lockを取り、対象siteのindex / artifactを削除できる。

サテライト側の権限

registryを読む。自分のsite lockをCAS更新し、自分のsite prefixだけ同期・stale削除できる。アプリ面とregistryは書き換えない。

同じ論理object modelをprovider adapterが実ストレージへ写像します。例: AWSではS3 + CloudFront、CloudflareではR2 + edge配信。ロックは公開配信面に含めません。
