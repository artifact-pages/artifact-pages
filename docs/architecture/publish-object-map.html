One node for each repository, operation, and object

Each repository and stored object appears once. Arrows show which operations read or write each object.

Delivery reads sites.json → meta.json → index.json → artifact. Locally, discovery uses the /_indexes/ directory listing.

CDN TTL: up to 60 seconds for indexes and 300 seconds for artifacts. Edge updates after unregister are eventually consistent.
