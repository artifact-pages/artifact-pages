Admin-side permissions

Can update the application plane and registry. Unregister acquires the site lock and can delete that site's indexes and artifacts.

Site publisher permissions

Can read the registry, update its own site lock with CAS, and sync or remove stale objects only under its site prefix. It cannot update the application plane or registry.

A provider adapter maps the same logical object model to storage. Examples: S3 + CloudFront on AWS, or R2 + edge delivery on Cloudflare. Lock objects are never part of the public delivery plane.
