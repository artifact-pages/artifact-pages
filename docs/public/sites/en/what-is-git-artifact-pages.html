What is Git Artifact Pages?

Git Artifact Pages turns HTML and Markdown already living in Git into a browsable, searchable website. Your repository stays authoritative; readers get ordinary links and a focused place to find and read the work.

Keep Git. Improve the last mile.

Artifacts deserve more than a file browser.

Useful work often ends up as a static file: an architecture page, a test report, an incident review, or a generated reference. Git is good at keeping that work reviewed and traceable. Git Artifact Pages adds the web experience around it—without becoming another place to edit or own the content.

  • Git is the source of truthChanges are made and reviewed in the source repository.
  • Routes point to real documentsPaths and file extensions are preserved for stable, explicit links.
  • Reader state is separateSearch, navigation, and personal pins do not mutate published content.

A small, repeatable workflow

From repository to reader

Git Artifact Pages prepares static files for reading. It does not run a site generator or require a request-time application server.

01 / SOURCE

Choose a site directory

A site maps one repository and source path to a stable route, such as /en/. Pages and their relative resources stay together.

02 / PROJECT

Build the reading index

The CLI records document titles, paths, and navigation metadata, then publishes that index beside the unchanged artifact files.

03 / DELIVER

Serve through storage and an edge

Object storage holds the static projection. A CDN or web edge delivers it; the browser app discovers, searches, and opens documents.

Know what you publish

Static does not mean access-controlled.

The browser reads published files from the configured delivery endpoint. Git Artifact Pages has no user accounts or per-site authorization; operators set any access gate at the CDN or hosting edge.

Content behavior

HTML is executable

HTML artifacts are published web documents. Only publish HTML from sources you trust. Markdown is sanitized and rendered in the native reader.

Viewer access

Set at the edge

VPN, identity-aware access, or another hosting policy belongs to the operator's delivery setup—not to a Git Artifact Pages account model.

Git Artifact Pages is an open-source publishing and reading layer for static artifacts. It keeps the content lifecycle in Git and makes the result easier to find and share on the web.
