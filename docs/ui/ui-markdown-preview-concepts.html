Experience

Useful for technical readers who want to verify a diagram, copy syntax, or inspect authored details.

Strength

Preview remains clean; source is available without leaving the artifact route.

Tradeoff

Adds a second view and state to support. It should stay secondary, not become an editor.

Route proposal: Keep the source extension in every indexed document’s URL: foo.html → /foo.html, foo.md → /foo.md, and README.md → /README.md. README.md is an ordinary, explicitly opened page—not an implicit directory landing page. For Markdown, use the document’s H1 as its user-facing title; the filename and extension provide its stable route identity.

Selected direction: A · Native reader. Render Markdown in the product’s reading surface, with the same Contents and Details controls as HTML pages. Keep HTML artifacts in their current browser-rendered view; choose a renderer based on each indexed document’s format.
