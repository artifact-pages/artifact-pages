Optional artifact details panel

Each option uses the same interaction as Contents: press a toolbar button to open the right-side panel, press the active button again to close it, or choose the other button to switch the panel's contents. The panel floats over the artifact view and does not resize it.

Shared behavior: Contents and Details are two views in one optional panel slot. No metadata row is added to the artifact header, and the document viewport keeps its full width.
