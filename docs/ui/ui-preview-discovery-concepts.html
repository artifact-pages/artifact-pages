Concept review · discovery only, not implemented

Where do previews live in the product?

A pull-request comment can deliver a direct link, but readers should also find active previews from Git Artifact Pages. These concepts keep previews out of published search results and distinguish temporary review material from the site's artifact tree.

Decision update: the site home links to the dedicated Previews list without showing preview entries. Expiry labels in these historical mocks are not part of the current contract; preview lifetime belongs entirely to the hosting provider. See the decision register.
