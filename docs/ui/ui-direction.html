Quiet navigation, fast search, clear reading.

This revision treats a site as the current working context. Site switching lives in the top bar, the site home is an artifact list, and command search handles the moment when a user knows what they want but not where it lives.

  • Sites belong in the top bar
  • ⌘K / Ctrl K opens search
  • /:site is an artifact list
  • Tree is current-site only
  • Low decoration, high signal

Site home is the page list

The site home answers “what is available here?” immediately. It keeps the current site in context, shows the index as a calm list, and lets the user jump to an artifact without making the home page look like a dashboard product.

A quieter artifact workspace

The left navigation contains only the current site's tree. It uses indentation, type, and a single active row instead of cards, badges, or decorative folder illustrations. The tree recedes so the rendered artifact stays primary.

Visual ruleUse spacing and typography to show hierarchy. Reserve borders and color for the active route, not every node.
