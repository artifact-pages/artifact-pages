How visible should preview identity be?

The artifact title remains its own H1. This compares where the application tells a reader that the same document is a temporary PR preview. No expiry countdown or new artifact controls are proposed.

The list uses a PR number and short head SHA to distinguish revisions. The question is whether a reader opening a direct document URL also needs that context in the application chrome.

Quietest reader

Provenance lives in the Previews list. Opening the document retains today's reader chrome unchanged.
