Git Artifact Pages / content neutrality review

The shell should frame HTML, not rewrite it.

An artifact might be a report, a dark operational dashboard, a wide data table, or a generated visualization. The viewer should feel native to all of them while keeping the surrounding product quiet and predictable.

  • Artifact CSS stays isolated
  • No forced white paper
  • No forced typography
  • Side panels can recede
  • Full-width content is allowed

01 / Product promise

Content owns the surface.

The SPA owns discovery and navigation. The iframe owns the artifact's visual language. This boundary lets a page bring its own CSS, scripts, assets, and responsive behavior without looking like a foreign object inside the app.

Correction to the earlier direction The paper-like viewer is useful for document artifacts, but it is too opinionated as the default for an arbitrary HTML publishing tool.

Outer chrome is neutral

Use a stable top bar and quiet borders. Do not impose a page background, font, or card treatment on the embedded artifact.

Navigation is reversible

The tree and table of contents can be hidden or overlaid so wide canvases and dashboards can use their full viewport.

Frame modes are explicit

Offer a normal view, a wide canvas view, and a focus view. These are viewer choices, not transformations of the HTML itself.

02 / Viewer concepts

Three ways to stay out of the artifact's way.

Each concept uses the same top-level product chrome and the same three content types. The difference is how much surface and framing the viewer adds around the iframe.

03 / Viewer behavior

Context should collapse, not compete.

A neutral shell is not only a color decision. It is also a state model: browse with context, read with focus, or inspect a wide artifact with the chrome out of the way.

Recommended default Start with the content-native canvas. Add the quiet workbench as an optional browse state instead of making every artifact carry three panes.

One viewer, three reversible modes

These modes change only the surrounding frame. They never inject styles into the artifact or convert its DOM into SPA components.

04 / Decision surface

Choose the shell by what it refuses to assume.

The strongest direction is the one that preserves the most artifact-native behavior while still making discovery and return navigation obvious.
