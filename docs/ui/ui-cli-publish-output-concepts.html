Shared output rules
    
        
  • Neutral text for operations, paths, action labels, and result sentences. Low-chroma green, amber, and red only for state labels and action symbols.
    • 
        
  • Neutral colors use the existing dark-theme tokens in web/src/styles.css. Semantic CLI status tones are proposed here; they are not yet a shared terminal palette.
    • 
        
  • Keep action labels and symbols meaningful without color.
    • 
        
  • Show the actual local root, or the provider's bucket and relevant target context.
    • 
        
  • Show preview reconciliation when references are pruned or groups are retained; hide an entirely empty preview section.
    • 
        
  • Use “synced” for local and remote publication, rather than calling local copies uploads.
    • 
      

      
Terminal and automation behavior
    
        
  • Enable color only on a suitable interactive terminal; honor NO_COLOR.
    • 
        
  • Keep piped output free of ANSI escapes and animation.
    • 
        
  • Preserve the existing --format json result contract and exit codes.
    • 
        
  • Send live progress to stderr. Emit the final structured result on stdout.
    • 
        
  • Failures must not present planned paths as successfully synchronized. A failed publish can already have made partial writes.
