CONCEPT A · RECOMMENDED BASE

Context first

The route chooses the default. Sites at /, this site's pages inside a site, and current-artifact headings only when explicitly requested.

Strength

One search surface

No extra controls to learn. The active site provides a quiet scope cue; familiar prefixes remain available for alternate intent.

Trade-off

Context must be legible

People need to notice which scope is active. Keep the site name visible and provide an explicit way to switch sites.
