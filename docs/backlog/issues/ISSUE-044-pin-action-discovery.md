# 閲覧中の文書をピン留めする入口が見つけにくい

- Status: Open
- Priority: P2
- Area: Artifact reading / Pin discovery

## Problem

初めて使う人が文書を保存しようとしても、ピン留め操作を見つけにくい。ピン0件では Pinned セクションがなく、文書ツールバーやコマンド一覧からも入口を発見できなかった。既存機能の故障ではなく、保存操作の発見性の改善。

## Evidence and reproduction

2026-10-01、Codex アプリ内ブラウザで確認。

1. ピン0件で `http://127.0.0.1:4179/guide/ja/reading.html` を開く。
2. 文書ツールバーとパレットの `>` 一覧にピン操作は見当たらなかった。
3. サイドバーの文書行の `…` を開くと Pin がある。
4. Pin／Unpin と再読み込み後の保持は動作した。

実装全体に別の入口がないと断定するものではなく、上記画面探索での観測。

## Expected outcome

ピン0件の利用者も、閲覧中の文書を後で読むために保存できることと、その操作方法を発見できる。

## Acceptance criteria

- [ ] ピン0件・文書閲覧中に、ピン留めの入口を画面上の手がかりから発見できる。
- [ ] サイドバーを閉じた状態でも現在の文書のピン操作へ辿れる。
- [ ] ピン済み状態と解除方法が明確で、既存の保持動作を損なわない。
