# サイト切替の初期候補をクリックできるのに Enter では開けない

- Status: Open
- Priority: P2
- Area: Site switcher / @ palette

## Problem

サイト切替を開いた直後に実行できる候補が見えていても Enter が無反応。クリックでは移動し、フッターには「↵ open」と表示されるため、キーボード利用者には必要な選択操作や無反応の理由が分からない。

## Evidence and reproduction

2026-10-01、Codex アプリ内ブラウザで確認。

1. `http://127.0.0.1:4179/guide/ja/reading.html` を開き、Guide のサイト切替を押す。
2. 入力が `@` のパレットに唯一の Guide 候補が出るが、初期選択は表示されない。
3. そのまま Enter を押しても変化しない。
4. 同じ候補をクリックすると `/guide` へ移動する。

確認範囲は現在サイト1件のみ。他サイトがある場合の初期選択は未検証。

## Expected outcome

サイト切替の選択状態と Enter の実行可否が明確で、クリックとキーボードの双方で同じ移動先へ進める。

## Acceptance criteria

- [ ] 現在サイト1件だけでも、開いた直後の選択状態と Enter で起こることが表示に一致する。
- [ ] 追加の候補選択が必要なら、その操作が画面から分かる。
- [ ] 現在サイト・別サイトの実行可能な候補をキーボードで選択して開ける。
