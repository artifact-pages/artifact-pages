# Preview implementation backlog

These are independently reviewable implementation slices for the [post-MVP preview contract](../../specification.md#post-mvp-pre-publish-preview-contract). They authorize no implementation by themselves. The repository remains in Phase 1; AWS infrastructure, Terraform, GitHub Actions publishing, and general-purpose CLI work still require an explicit implementation request. Product behavior belongs in the specification, technical choices in T1–T3, and proof in T4–T8. A ticket is `Done` only when its acceptance criteria have evidence; completing a ticket does not mark a linked verification item `Done` automatically.

Suggested path: settle only the minimum T1 shape needed for IMP-01, then prove IMP-02/03 and IMP-07/08 locally with fixtures. Use that producer/reader round trip to finish T1. IMP-04/05/06/16 establish publication and lifecycle correctness; IMP-09/10 establish discovery and PR return navigation. T2 fixes the public command surface before IMP-11/13. IMP-12/14 cover provider storage and serving; T3 fixes retention mapping before IMP-15. No dependency on AWS is imposed on local browser/projection work.

The table is a traceability map, not a claim that every linked test has run. The linked verification items own final evidence. Optimization or a changed read model is follow-up work only if [T7](../verification/T7-discovery-performance.md) shows a real bottleneck.
